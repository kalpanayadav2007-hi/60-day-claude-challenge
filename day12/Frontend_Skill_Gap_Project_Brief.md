# Frontend Skill-Gap Project Brief
**Goal: turn Sections 9–10 of your toolkit from "learning toward" into "demonstrated" — with real GitHub repos and resume-ready proof points.**

Each project below is scoped to be realistically finishable in the stated window, given you already have solid HTML5/CSS3/JS fundamentals. Build them in order — each one reuses skills from the last.

---

## Project 1: Responsive/Mobile-First Landing Page
**Timeframe:** Weekend 1 (Week 1–2)
**Closes:** Responsive design, mobile-first approach, browser DevTools

**Brief:** Build a single-page site (a portfolio landing page, a fictional product page, or a café/business page) that is designed mobile-first and scales up to tablet and desktop using media queries.

**Must include:**
- Flexbox and/or CSS Grid for layout
- At least 3 breakpoints (mobile, tablet, desktop)
- A responsive nav (hamburger menu on mobile → full nav on desktop)
- Verified in Chrome DevTools device toolbar across at least 3 device sizes

**Resume/portfolio proof point this earns you:**
"Built a fully responsive, mobile-first landing page using Flexbox/Grid and CSS media queries; tested across device breakpoints using Chrome DevTools."

**Free resources:** Kevin Powell's YouTube channel (Flexbox/Grid + responsive design), MDN's responsive design guide.

---

## Project 2: Rebuild in a Framework (Tailwind CSS recommended)
**Timeframe:** Weekend 2 (Week 2–3)
**Closes:** CSS framework proficiency (the posting's #3 requirement)

**Brief:** Take the landing page from Project 1 and rebuild it using Tailwind CSS utility classes instead of hand-written CSS. This is faster than starting a new project and lets you directly compare "vanilla CSS vs. framework" — a good talking point for interviews.

*Why Tailwind over Bootstrap:* Tailwind is currently more in-demand in frontend job postings and demonstrates utility-first thinking, which is closer to how modern teams work. If a specific employer's stack uses Bootstrap, learning Bootstrap afterward is a quick lateral move once you understand the concepts.

**Must include:**
- Same responsive behavior as Project 1, implemented with Tailwind classes
- A short README explaining what changed and why (this alone is a great interview story)

**Resume/portfolio proof point:**
"Rebuilt a responsive landing page using Tailwind CSS, applying utility-first styling and responsive breakpoint classes."

**Free resources:** Tailwind CSS official docs (excellent for beginners), Tailwind Play (in-browser sandbox, no setup needed).

---

## Project 3: Figma-to-Code Implementation
**Timeframe:** Weekend 3 (Week 3–4)
**Closes:** Design-to-code implementation (the posting's #5 requirement — your biggest true gap)

**Brief:** Find a free, beginner-friendly Figma community template (search "Figma community free landing page template") and implement it in HTML/CSS as closely to pixel-accurate as you can.

**Must include:**
- Screenshot comparison (Figma design vs. your built page) in the README — this is exactly what a hiring manager wants to see
- Correct spacing, font sizes, and colors pulled directly from the Figma file's inspect panel (this is the actual skill being tested — reading specs off a design tool, not guessing)

**Resume/portfolio proof point:**
"Implemented a Figma design into responsive HTML/CSS, translating design specifications (spacing, typography, color) into production code."

**Free resources:** Figma's free "Inspect" mode tutorial (no design skill needed — you're just reading measurements off an existing file).

## Deployment & Packaging (do this alongside every project above)

- Push each project to a separate GitHub repo with a clear README (what it is, what it demonstrates, tech used)
- Deploy each one live via **Netlify** or **Vercel** (both free, both take under 10 minutes) — a live link is significantly more convincing to a recruiter than a repo alone
- Once you have all 3 links, add a **Projects** section to your resume, above or below Experience:

```

Responsive Landing Page | HTML5, CSS3, Flexbox/Grid | [live link] | [GitHub link]

```
