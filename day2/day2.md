# Day 2 – Prompt Engineering Comparison

## Objective

Understand the difference between a simple prompt and an engineered prompt.

---

## Lazy Prompt

Create an image explaining Prompt Engineering.

---

## Engineered Prompt

Act as an expert AI educator.

Create a beginner-friendly infographic explaining Prompt Engineering.

Include:
- Definition
- Importance
- Examples
- Best Practices
- Common Mistakes
- Attractive Layout

---

## Comparison

### Lazy Prompt Output

- Simple explanation
- Minimal details
- Basic image

### Engineered Prompt Output

- Better organized
- More detailed
- Better visual design
- Included examples

---

## Key Learnings

- Prompt engineering improves AI responses.
- Providing context leads to better results.
- Structured prompts produce clearer explanations.
- Specific instructions improve image quality.
