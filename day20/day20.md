# Day 20 – Face Puzzle Game

## Objective

The objective of this project was to build an interactive Face Puzzle Game using HTML, CSS, and JavaScript. The application allows users to capture their photo using the webcam, convert it into a puzzle, and solve it while tracking time and moves. The project also demonstrates drag-and-drop interactions, touch support, and responsive web design.

---

## Project Overview

The Face Puzzle Game captures an image from the user's webcam and divides it into puzzle pieces based on the selected difficulty level. The pieces are shuffled, and the player must rearrange them to recreate the original image. The game records the completion time, number of moves, and displays the final results.

---

## Features

- 📷 Webcam integration for capturing a custom photo.
- 🧩 Multiple puzzle difficulty levels:
  - 3 × 3 (Easy)
  - 4 × 4 (Medium)
  - 5 × 5 (Hard)
- 🖱️ Drag-and-drop support for desktop users.
- 📱 Touch support for mobile devices.
- ⏱️ Real-time timer.
- 🔢 Move counter.
- 🏆 Leaderboard to track completed games.
- 📱 Responsive design for different screen sizes.
- 🎨 Attractive and interactive user interface.
