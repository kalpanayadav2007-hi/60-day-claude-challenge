# Day 28 — Hospital Admission Readiness Simulator

## 🚀 Project Overview

For Day 28, I built a Hospital Admission Readiness Simulator using Claude.

The simulator evaluates whether a hospital admission is ready to proceed by considering factors such as clinical risk, documentation, insurance, prior authorization, bed availability, and admission workflow requirements.

## 🎯 Objective

The objective of this project was to create an interactive simulator that:

- Collects provider and physician information
- Allows diagnosis and admission type selection
- Handles Prior Authorization scenarios
- Calculates an admission readiness score
- Identifies admission risks
- Provides workflow actions to improve readiness
- Displays governance information
- Produces a final admission decision

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Claude AI
- Browser-based application

## ⚙️ Features

### Provider & Physician Details

The simulator collects the required provider and physician information.

### Diagnosis Selection

Users can select different diagnosis scenarios and evaluate their admission readiness.

### Admission Type

The application supports different admission types and adjusts the workflow accordingly.

### Prior Authorization

The simulator handles different authorization situations including:

- Approved
- Pending
- Denied
- Appeal

### Readiness Score

The application generates an initial readiness score and updates it as workflow risks are resolved.

### Risk Management

The simulator evaluates risks related to:

- Clinical requirements
- Documentation
- Insurance
- Bed availability
- Prior Authorization

### Governance Snapshot

The Governance Snapshot provides a high-level view of the admission decision and remaining risks.

### Final Admission Decision

After completing the workflow, the simulator provides a final admission readiness decision.
