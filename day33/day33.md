# Day 33 — Media Integrity Analyzer

## Overview

For Day 33, I built and tested a **Media Integrity Analyzer** web application designed to help identify misleading headlines and emotional manipulation in media content.

The application provides interactive challenges and a live Media Integrity Dashboard that shows how different analysis results affect overall media integrity metrics.

## What I Built

The Media Integrity Analyzer includes:

* Headline Detective challenge
* Headline analysis
* Rewritten headline suggestions
* Emotion Detector challenge
* Emotional manipulation analysis
* Live Media Integrity metrics
* Final Media Integrity Dashboard
* Randomized scenarios for replay
* Color theme selection
* Interactive HTML interface

## Challenges Completed

### 1. Headline Detective

I analyzed headlines to identify potentially misleading or manipulative wording.

The analyzer helped identify issues such as:

* Sensational language
* Exaggerated claims
* Missing context
* Biased wording
* Clickbait-style headlines

It also generated a more neutral and informative rewritten headline.

### 2. Emotion Detector

I analyzed headlines and media content for emotional manipulation techniques.

The analysis focused on techniques such as:

* Fear
* Anger
* Shock
* Urgency
* Outrage
* Emotional exaggeration

This helped me understand how emotional language can influence the way people interpret information.

## Media Integrity Dashboard

The application continuously updates its media integrity metrics based on the analysis results.

The dashboard provides an overall view of the quality and reliability of the analyzed media content.

## Randomized Scenarios

I replayed the application using different randomized scenarios.

This helped test how the analyzer responds to different types of headlines and emotional manipulation patterns instead of relying on only one example.

## Key Learnings

1. Headlines can strongly influence how readers interpret a story.
2. Sensational wording can make information appear more extreme than it actually is.
3. Emotional manipulation can affect people's judgment.
4. Rewriting a headline in neutral language can improve clarity and reduce bias.
5. Media analysis should consider both factual content and emotional presentation.
6. Interactive tools can make media-literacy concepts easier to understand.
7. Building the project with HTML, CSS, and JavaScript helped me practice creating an interactive web application.
