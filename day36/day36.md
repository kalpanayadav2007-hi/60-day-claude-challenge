# Day 36 – Cognitive Pattern Explorer

## Overview

For Day 36, I created and explored an interactive **Cognitive Pattern Explorer** application using Claude.

The goal of this activity was to explore how different situations and environments can influence the way we think, make decisions, and respond to everyday scenarios.

The application provides two different experiences:

* **Calm Mode**
* **Stress Mode**

I completed the interactive chapters in both modes and reviewed the resulting Reflection Journal and Thinking Profile.

---

## Objective

The main objectives of this challenge were:

* Practice using Claude to generate a complete web application.
* Understand how an interactive HTML application can be created from a prompt.
* Explore different cognitive patterns through interactive scenarios.
* Compare responses between Calm Mode and Stress Mode.
* Analyze the personalized Reflection Journal.
* Review my thinking tendencies across multiple chapters.
* Document the complete experience in GitHub.

---

## Tools Used

* Claude
* HTML

## Application

The project is a standalone HTML application called:

`cognitive-pattern-explorer.html`

The application can be opened directly in a web browser without requiring a backend server.

---

## How I Created the Application

### Step 1 – Opened Claude

I opened Claude and started a new conversation.

### Step 2 – Changed Effort Level

I set the Claude effort level to **Low**, as required by the challenge.

### Step 3 – Provided the Prompt

I pasted the provided **Cognitive Pattern Explorer** prompt into the new Claude conversation.

### Step 4 – Generated the Application

Claude generated the complete HTML application.

I saved the generated code as:

`cognitive-pattern-explorer.html`

### Step 5 – Tested the Application

I opened the HTML file in my browser and interacted with the application.

## Chapters Completed

### Chapter 1 – Everyday Scenarios

In Chapter 1, I responded to different everyday scenarios.

## Calm Mode vs Stress Mode

I completed the experience in both modes.

### Calm Mode

In Calm Mode, I focused on responding to the scenarios with a more relaxed approach.

I had more opportunity to consider the situation before choosing a response.

### Stress Mode

In Stress Mode, the experience encouraged me to respond under a more pressured environment.

This provided an opportunity to compare how my responses differed from Calm Mode.

### Comparison

The comparison between the two modes helped me understand that the same person can approach a situation differently depending on the surrounding conditions.

This was one of the most interesting parts of the challenge.

## Key Learnings

### 1. Prompts can generate complete applications

One important learning was that a well-designed prompt can instruct an AI system to generate an entire interactive web application.

### 2. HTML can create standalone applications

A single HTML file can contain the structure, styling, and JavaScript required for a small interactive application.

### 3. User interaction makes learning more effective

Instead of simply reading information, interacting with scenarios made the concepts easier to understand.

### 4. Context can influence decisions

The Calm Mode and Stress Mode comparison showed how the environment surrounding a decision can affect the way we respond.

### 5. Reflection is important

The Reflection Journal helped convert the interactive experience into meaningful observations about my thinking patterns.

### 6. AI can be used as a creative development tool

Claude was useful not only for answering questions but also for generating a complete working frontend application from a detailed prompt.
