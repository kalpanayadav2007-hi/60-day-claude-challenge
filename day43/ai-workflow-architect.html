Workflow summary & what's next

Workflow summary

A recurring weekly loop: plan Sunday, protect three daily lanes (college / job search / skill-build), review Friday, adjust the following Sunday. The RAG chatbot is the single project that should exist on GitHub within 4–6 weeks of consistent lane time.

Recommended AI stack

  • Claude or ChatGPT — planning, prompt drafting, code debugging
  • GitHub Copilot or Claude in your editor — while building the RAG project
  • Jobscan — real ATS scoring once resume has project content
