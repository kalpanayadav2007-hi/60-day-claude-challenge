## 💡 Project Overview

The main task was to transform the provided prompt and requirements into a complete browser-based decision workflow application.

Claude was used to understand the requirements, conduct the required interview process, and generate the final HTML application. The generated application was then saved locally and tested directly in the browser.

## 🧪 Testing

After generating the application, I opened the HTML file locally and tested the complete workflow.

The testing focused on:

1. Starting the decision workflow.
2. Providing the required inputs.
3. Moving through each decision stage.
4. Checking that the interface responded correctly.
5. Verifying that the final decision/output was generated properly.
6. Confirming that the application worked without requiring a backend server.

## 🧠 Key Learnings

### 1. AI-Assisted Development

I learned how Claude can be used not only for generating code but also for understanding requirements, asking clarification questions, and designing an application based on a structured prompt.

### 2. Prompt Engineering

A detailed prompt can significantly improve the quality of the generated application. Providing clear requirements, expected workflow, and desired functionality helps the AI produce more useful results.

### 3. Building Complete HTML Applications

I practiced creating a complete browser application using HTML, CSS, and JavaScript in a single file.

### 4. Testing AI-Generated Code

AI-generated code should always be tested manually. Running the application locally helped identify whether the generated workflow behaved as expected.

### 5. GitHub Documentation

I learned how to organize project files inside a dedicated daily folder and document the work using Markdown.

### 6. End-to-End Workflow

This task helped me understand the complete process:

**Prompt → AI Interview → Code Generation → Local Testing → Screenshots → Documentation → GitHub**
