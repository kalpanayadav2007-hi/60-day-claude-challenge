# Day 48 – The Verdict Engine

## 📌 Project Overview

Day 48 focused on building **The Verdict Engine**, an AI-powered decision-making application designed to compare multiple options using weighted criteria, researched data, and transparent sources.

The application helps users make better decisions by combining criteria weights, evidence, source information, and conflict resolution into a single ranking system.

---

## 🎯 Objective

The main objective of this project was to build a decision-support application that can:

* Compare multiple options
* Define and adjust decision criteria
* Assign weights to different criteria
* Calculate rankings based on weighted scores
* Update rankings dynamically when weights change
* Display sources for individual data points
* Explain how research was performed
* Show how conflicting information was resolved
* Provide a transparent and evidence-based decision process

## ⚖️ Decision Criteria and Live Ranking

One of the main features tested was the ability to adjust the **criteria weights**.

The application recalculates the rankings when the weights are changed.

For example:

```text
Criteria
   ↓
Assign Weights
   ↓
Calculate Scores
   ↓
Update Rankings
   ↓
Compare Results
```

This makes it possible to understand how different priorities affect the final recommendation.

## 🧠 Key Learnings

### 1. Weighted Decision Making

I learned how different criteria can be assigned different weights based on their importance.

A higher weight means that a criterion has a greater influence on the final ranking.

### 2. Dynamic Ranking

The application demonstrated how rankings can update immediately when criteria weights are changed.

This makes the decision process interactive rather than static.

### 3. Evidence-Based Decisions

A decision system becomes more trustworthy when every important data point can be traced back to a source.

### 4. Research Transparency

The **How this was researched** panel helped demonstrate the importance of explaining where information came from and how it was evaluated.

### 5. Conflict Resolution

Different sources may provide different information. I learned that a reliable decision system should identify these conflicts and explain how they were resolved rather than silently choosing one value.

### 6. AI-Assisted Application Development

Claude can be used to generate a complete functional web application from a detailed product prompt and user requirements.

### 7. Explainable AI

The project showed how AI-powered recommendations can become more useful when the system explains:

* What information was used
* Where the information came from
* How criteria were weighted
* Why an option ranked higher
* How conflicting information was handled

---

## 💡 Key Takeaway

The main takeaway from Day 48 is that **good decision-making is not only about producing a recommendation; it is also about making the reasoning behind that recommendation transparent.**

The Verdict Engine combines weighted criteria, researched data, source attribution, and conflict resolution to create a more explainable decision-making workflow.
