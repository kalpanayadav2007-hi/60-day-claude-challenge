# 30-Day Web Development Roadmap (JavaScript + React)

**Goal:** Go from beginner to being able to build and deploy a functional React app.
**Time commitment:** ~1.5–2.5 hours/day. Adjust pacing as needed — this is a guide, not a race.

---

## Week 1: HTML, CSS & JavaScript Foundations
**Milestone:** Comfortable writing structured HTML/CSS and basic JS logic.

| Day | Task |
|---|---|
| 1 | HTML basics: tags, semantic elements, forms. Build a static bio page. |
| 2 | CSS basics: selectors, box model, flexbox. Style yesterday's page. |
| 3 | CSS Grid + responsive design (media queries). Make the page mobile-friendly. |
| 4 | JS basics: variables, data types, operators, conditionals. |
| 5 | JS functions, arrays, loops. |
| 6 | JS objects, `this`, and the DOM (querySelector, addEventListener). |
| 7 | **Project 1:** Build an interactive to-do list (HTML/CSS/vanilla JS) — add, delete, mark complete. |

**Resources:**
- [MDN Web Docs — HTML](https://developer.mozilla.org/en-US/docs/Web/HTML) / [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS) / [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
- [freeCodeCamp — Responsive Web Design](https://www.freecodecamp.org/learn/2022/responsive-web-design/)
- [JavaScript.info](https://javascript.info/) (fundamentals section)

---

## Week 2: Modern JavaScript & Async Programming
**Milestone:** Confident with ES6+ syntax, array methods, and async data fetching.

| Day | Task |
|---|---|
| 8 | ES6+ syntax: `let`/`const`, arrow functions, template literals, destructuring. |
| 9 | Array methods: `map`, `filter`, `reduce`, `forEach`. |
| 10 | Modules (`import`/`export`), spread/rest operators. |
| 11 | Promises and `async`/`await`. |
| 12 | `fetch` API — pull data from a public API (e.g., a weather or joke API). |
| 13 | Error handling (`try`/`catch`) + practice combining fetch + array methods. |
| 14 | **Project 2:** Build a "random quote / joke generator" that fetches from a public API and displays results dynamically. |

**Resources:**
- [javascript.info — Promises, async/await](https://javascript.info/async)
- [Public APIs list](https://github.com/public-apis/public-apis) (pick a simple, free, no-auth API)

---

## Week 3: React Fundamentals
**Milestone:** Able to build multi-component React apps with state and props.

| Day | Task |
|---|---|
| 15 | What is React & why. Set up a project with Vite. JSX basics. |
| 16 | Components & props — build small reusable components. |
| 17 | State with `useState`. Handling events in React. |
| 18 | Conditional rendering + rendering lists (`.map` with `key`). |
| 19 | Forms in React — controlled inputs. |
| 20 | `useEffect` — side effects, fetching data in React. |
| 21 | **Project 3:** Rebuild your Week 2 quote/joke generator as a React app. |

**Resources:**
- [React official docs — Learn React](https://react.dev/learn)
- [Vite — Getting Started](https://vitejs.dev/guide/)

---

## Week 4: Building & Shipping a Real Project
**Milestone:** A deployed, portfolio-ready React application.

| Day | Task |
|---|---|
| 22 | Plan a capstone project (see below). Sketch component structure + data flow. |
| 23 | Set up project scaffold, routing with `react-router-dom`. |
| 24 | Build core components + layout. |
| 25 | Add state management and API/data integration. |
| 26 | Styling pass (CSS modules, Tailwind, or plain CSS — your choice). |
| 27 | Bug fixing, edge cases, responsiveness check. |
| 28 | Polish: loading states, error states, empty states. |
| 29 | Deploy (Vercel or Netlify — both free and beginner-friendly). Write a README. |
| 30 | Reflect: write a short case study of what you built and what you'd improve. Share it. |

**Capstone project ideas (pick one):**
- A recipe finder using a public recipe API
- A personal expense tracker with local storage
- A movie/show search app using a public movie API
- A simple multi-page blog with routing

**Resources:**
- [React Router docs](https://reactrouter.com/en/main)
- [Vercel deployment guide](https://vercel.com/docs)
- [Tailwind CSS docs](https://tailwindcss.com/docs) (optional styling option)

---

## Final Outcome
By day 30, you'll have:
- Three built projects (to-do list, API-driven app, React rebuild) plus one deployed capstone app
- Working knowledge of HTML/CSS, modern JavaScript, and core React (components, state, props, hooks, routing)
- A live URL and README you can put in a portfolio or share with others
- A concrete sense of what part of web dev (frontend, full-stack, styling, etc.) you want to go deeper on next

## Tips for staying on track
- Don't skip the projects — they're where the concepts actually stick.
- If a day's task takes longer than planned, let the schedule slip rather than skipping fundamentals.
- Keep a short daily log (3 bullet points: what you did, what confused you, what to revisit) — it becomes a fast way to spot patterns in what trips you up.
